# CampusConnect
تُعد المشاركة في الأنشطة الطلابية والفعاليات المختلفة من أهم الفرص التي تساعد الطلاب على اكتساب خبرات جديدة وتطوير مهاراتهم وبناء علاقات مهنية وشخصية. لكن الوصول إلى هذه الفرص ومتابعة مواعيدها وتفاصيلها قد لا يكون سهلًا، خاصة مع تشتت المعلومات بين مصادر مختلفة. ومن هنا جاءت فكرة CampusConnect، وهي منصة تهدف إلى تجميع الأنشطة والفعاليات الطلابية
